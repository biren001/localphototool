Colour profile

Metadata is a label, not a layer of paint

Most online "metadata editors" load your photo into a canvas, let you type fields into a form, and then re-encode the whole image to hand you a file with the new labels. The pixels get regenerated on the way: a quality setting is chosen for you, generation is lost, and a picture that was crisp at 480 KB comes back softer at 520 KB. The label changed; the painting got repainted to hang it.

This tool takes the other route. EXIF, XMP and IPTC live in container segments that sit next to the compressed pixels, not inside them. So the editor copies the image data through untouched, rewrites only those segments, and hands you back a file whose picture is byte-for-byte identical to the one you dropped in. The file size moves by a few hundred bytes — the size of the metadata itself — and nothing else.

What it removes, and what it writes

  • Removed, always. EXIF blocks (camera model, exposure settings, GPS coordinates, the embedded preview thumbnail), existing XMP packets and IPTC records from JPEG; text and eXIf chunks from PNG; EXIF and XMP chunks from WebP. What was found in each file is shown per row before you download anything.
  • Written, if you fill the fields. Title, creator, description, copyright, keywords and tool name, as one standards-compliant XMP packet — readable by Lightroom, Photoshop, Windows Photos, macOS Preview and every photo library that matters.
  • Optional. The ICC colour profile survives by default; tick the box to remove it too, for the rare workflow that demands a profile-free file.

Why fields-empty is a feature

Submit the form with nothing filled in and the tool becomes a total metadata stripper: every EXIF, XMP and IPTC block goes, and nothing is written back. That is the same lossless scrub the dedicated GPS remover performs — this page is the same operation wearing an editor's interface, for when you want the blocks gone and new fields written in. Use it before selling a camera with its cards, publishing a portfolio, or handing files to anyone who does not need the shooting history.

Honest limits

New XMP is written into JPG and PNG. WebP files get their EXIF and XMP chunks stripped, but this tool does not write new metadata into them losslessly — the WebP container gates its metadata behind a header flag that has to be rewritten carefully, and a half-correct edit there is worse than none. Files in other formats pass through untouched. JPEG files are also limited to one XMP packet per file, which is what every reader expects anyway.

Frequently asked questions

What does lossless metadata editing mean?

Metadata lives in container segments that sit next to the pixels, not inside them. This tool rewrites only those segments: the compressed image data is copied byte-for-byte, so the picture is never decoded or re-encoded and its quality cannot change. The file size shifts by a few hundred bytes — the size of the metadata itself — and nothing else.

Which metadata is removed, and which can I add?

Removed: EXIF (camera, settings, GPS coordinates, embedded thumbnail), XMP and IPTC from JPEG files; text and eXIf chunks from PNG files; EXIF and XMP chunks from WebP files. An option also removes the ICC colour profile. Added: your title, creator, description, copyright, keywords and tool name, written as a standard XMP packet. New XMP can be written into JPG and PNG; for WebP this tool strips only.

Will the image look different afterwards?

No. The pixels are untouched, so the picture renders exactly as before. The one exception is the optional colour-profile removal: if you tick it, apps that ignore colour management may interpret the colours slightly differently. Leave the box unticked and the profile survives along with everything visual. One thing to know: portrait photos are often stored landscape with an EXIF orientation flag that rotates them on display, and that flag goes with the EXIF block — affected files are flagged with an ORIENTATION badge, and the GPS-removal tool's FAQ explains the fix.

Does it work on a phone?

Yes. Each edited file has its own download button, and the files land in your browser's downloads. On desktop, and on Android, a batch can also be taken as one ZIP archive; iPhones get per-file downloads instead, because iOS does not unpack ZIPs into the photo library.

Are my photos uploaded to a server?

No. This is a static site with no upload endpoint. The files are read and rewritten in your browser, on your own device — you can watch the network tab and confirm that nothing leaves it.

Why leave fields empty on purpose?

Submitting with every field empty is the quickest way to strip metadata: all EXIF, XMP and IPTC blocks are removed and nothing is written back. It is the same lossless scrub as the dedicated GPS-removal tool — this page simply frames it as the empty-fields path of a full editor. Useful before selling a camera, publishing a portfolio, or sending files to a printer.
